# Screenshots – Shot-Liste (zum Einfügen durch Menschen)

Bilder sagen Neulingen mehr als Text. Diese Screenshots fehlen noch und können
von jeder Person mit installiertem Godot aufgenommen und hier abgelegt werden.
Sobald eine PNG hier liegt, in [QUICKSTART.md](../../QUICKSTART.md) bzw.
[ORIENTIERUNG.md](../../ORIENTIERUNG.md) den passenden `<!-- 📷 -->`-Platzhalter
durch das Bild ersetzen.

## So machst du gute Anleitungs-Screenshots
- Godot-Fenster auf **deutsche Sprache** stellen (Editor-Einstellungen), damit
  Beschriftungen zur Doku passen.
- Wichtige Stelle mit einem **roten Rahmen/Pfeil** markieren (jedes Mal-Programm
  reicht).
- Als **PNG** speichern, Breite ca. **1000–1400 px** (nicht riesig).
- Dateinamen **genau** wie unten verwenden.

## Benötigte Bilder

| Datei | Was drauf sein soll | Wird verwendet in |
|---|---|---|
| `01_import.png` | Projektmanager mit „Importieren"-Dialog, `project.godot` ausgewählt | QUICKSTART Schritt 1 |
| `02_filesystem_sandbox.png` | FileSystem-Dock, Pfad `scenes/levels/sandbox.tscn` rot markiert | QUICKSTART Schritt 2 |
| `03_play_buttons.png` | Editor-Oberfläche mit F5/F6-Play-Buttons (oben rechts) markiert | QUICKSTART Schritt 3 |
| `04_drag_coin.png` | `coin.tscn` wird ins 2D-Viewport gezogen (Pfeil) | QUICKSTART Schritt 4 |
| `05_inspector_export.png` | Plattform angeklickt, Inspector mit `speed`/`distance` markiert | QUICKSTART Schritt 5 |
| `06_layout_overview.png` | Gesamtes Fenster mit beschrifteten Bereichen (Szene-Baum, FileSystem, Inspector, Viewport, Output) | ORIENTIERUNG „Das Fenster auf einen Blick" |
| `07_git_panel.png` | Godot „Version Control"-Panel unten, Commit-Feld markiert | CONTRIBUTING „Git ohne Terminal" |

> Bis echte Screenshots da sind, helfen die ASCII-Skizzen in ORIENTIERUNG.md
> und die Schritt-für-Schritt-Texte. Die Doku funktioniert also auch **ohne**
> Bilder – sie werden nur schöner damit.
