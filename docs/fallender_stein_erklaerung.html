Warum machen die fallenden Steine keinen Schaden?

Der Stein hat eine Trefferzone und eine Schadens-Funktion. Trotzdem passiert nichts – weil die beiden nie miteinander verbunden wurden.

So entsteht Schaden – eine Kette aus 4 Gliedern
1
Trefferzone (Area2D) bemerkt den Spielersendet das Signal body_entered(body)
↓
2
Signal wird mit einer Funktion VERBUNDEN.connect(...) — der „Draht"
✗ FEHLT
↓
3
Funktion läuft & prüft: Ist das der Spieler?if body.has_method("take_damage")
↓
4
take_damage() → Spieler verliert Lebenbody.take_damage(1, …)

Fehlt ein Glied, passiert nichts. Beim Stein fehlt genau Glied 2 – die anderen drei sind korrekt da.

Die Funktion ist da – aber niemand ruft sie auf
# in falling_rock.gd
func _on_FallingRock_entered(body):
    if body.has_method("take_damage"):
        body.take_damage(1, knockback_dir)   # ✔ richtig geschrieben

Der Code stimmt. Aber im ganzen File gibt es kein .connect(...) und in der Szene keine Signal-Verbindung → die Funktion ist eine Waise und wird nie aufgerufen.

Gleiche Aufgabe – beim Slime fehlt nur diese eine Zutat nicht
SlimeFallender Stein
Trefferzone (Area2D)✔✔

# slime_base.gd – DAS ist der „Draht", den der Stein nicht hat:
hitbox.body_entered.connect(_on_hitbox_body_entered)
Die Lösung
Eine Zeile in falling_rock.gd, in _ready(): 
$Sprite2D/Hitbox.body_entered.connect(_on_FallingRock_entered)

Pfad $Sprite2D/Hitbox, weil die Trefferzone unter dem Sprite hängt – nicht direkt unter dem Stein.

💡 Merksatz: Eine Funktion für ein Signal zu schreiben ist nur die halbe Arbeit – man muss das Signal auch mit ihr verbinden (.connect), sonst wird sie nie aufgerufen.
